# EAB — Reading Phase 2 Data (Win-Factor Carryover)

## Purpose

Before opening any EAB round, check what Phase 2 already revealed about the winning combo. This isn't a prerequisite — if there's nothing to read (the Phase 2 simple path was used, or the data wasn't tracked), skip straight to the default element priority order in `eab-isolated.md` or `eab-multi.md`.

## What to look for

Pull the winning combo's read from the Phase 2 doc/log, if it exists:

| Phase 2 verdict | What it means for EAB |
|---|---|
| **Delivery confirmed as the win-factor** (Strong cluster on the delivery axis) | Keep hook/visual/body variants operating inside that delivery's structural logic — e.g. don't let a hook variant drift out of a problem→solution arc if that arc is what's proven. |
| **Angle confirmed as the win-factor** (Strong cluster on the angle axis) | Keep variants inside that angle's message and emotional register — vary the execution, not the underlying claim. |
| **Neither axis independently confirmed** (isolated/hedged pairing — a "best single ad, no cluster backing" case) | Treat EAB as a second chance to diagnose. Document which single-element swap moves the needle most — that result becomes indirect evidence about whether the delivery, the angle, or neither was actually doing the work. |
| **No Phase 2 read available** | Proceed with the default element priority order below (or see eab-isolated.md it has element priority covered in it). No carryover to apply. |

## Multiple surviving directions

If more than one combo survived Phase 2, pick one as the primary EAB subject. Use the others as supporting context only — e.g. an element that clearly worked on one combo is worth trying on another — rather than running full parallel EAB tracks, unless budget genuinely allows it.

## Traceability

Every winning ad has a paper trail: the original generation prompt, the thinking behind it, and — where available — its Phase 2 data. Pull from all of it when deciding what to test. Don't rebuild the win-factor read from scratch if it's already sitting in the record.
