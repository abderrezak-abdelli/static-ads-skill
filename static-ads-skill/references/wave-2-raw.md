# Meta Ads — Phase 2 (Simple Path): Wave 1 Winner → AOD + DOA

## Scope

A lighter alternative to the main Phase 2 doc. Use this when the top Wave 1 winner is being handed over directly rather than derived through the tiering/clustering read.

## Input

The user states the top-performing angle + delivery combo from Wave 1. Take it as given — no need to re-derive it from the results table.

## Action

Expand that combo into two ad sets, built together under one CBO and left to run:

- **AOD** — the winning angle, paired with a set of deliveries.
- **DOA** — the winning delivery, paired with a set of angles.

Full catalog of angles and deliveries already tried lives in the Wave 1 file — pull from there to avoid retreading the same ground, but there's no need to restate that list here.

## More than one winner

If the user hands over more than one top winner, repeat the same expansion for each, or ask the user which to prioritize first if resources don't allow running them all at once.

## Next step

Once either ad set produces a repeat winner, that combo moves on to Element A/B testing.
